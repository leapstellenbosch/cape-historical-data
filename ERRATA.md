# Errata

Errors found after the release of version 1.0 are listed here, newest first,
with the file, the record (`chdr_id`, or file and reference for the XML), what
is wrong and the correct value where known. Record identifiers never change.
If corrections accumulate, they will be applied in a new version with its own
DOI.

To report an error, open an issue on GitHub or write to leap@sun.ac.za.
